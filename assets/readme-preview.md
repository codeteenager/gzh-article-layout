# 用 AI Agent 稳定完成公众号排版

> 把写好的文章交给排版 Skill，快速生成可预览、可复制、可检查的公众号正文。

## 从文章到公众号正文

先准备 Markdown 文章，再告诉 Agent 使用 `gzh-article-layout` 排版。没有指定主题和版式时，默认使用「墨规·翡翠林木」与墨规版式。

### 保留文章原意

排版关注内容层级，不改写文章的事实和观点。标题、引用、列表、代码与图片会按文章结构组织。

## 选择适合的视觉风格

项目包含 15 套色系与三种章节版式。色系决定整篇文章的配色，版式决定章节标题的呈现，两者可以自由组合。

### 三种章节版式

- 墨规：编号标尺，章节层级清晰。
- 浮光：透叠式大数字，视觉更鲜明。
- 素墨：克制留白，不显示可见章节编号。

## 预览、复制与校验

生成后先在浏览器预览，确认标题、图片、代码和名片等组件，再复制到公众号编辑器。HTML 校验脚本会检查平台兼容规则；图片仍需使用公众号可访问的地址。

::: tip 使用建议
首次发布前，请在目标公众号编辑器中实际粘贴检查。不同客户端和编辑器版本可能影响最终显示。
:::
