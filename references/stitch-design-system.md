# Magazine Markdown Converter · 设计来源与公众号适配

> **维护入口**：主题采用 Markdown 唯一源码，直接修改 `references/theme-*.md` 与 `references/theme-index.md`。原稿、冻结样式与清单用于来源证据及设计对照；主题定义以 Markdown 为准。来源定制和优化过程见 `docs/design-history.md`。

## 原稿与主题不能混为一谈

来源项目：`projects/9891162362575619920`。五份来源导出的本地副本及 SHA-256 清单保存在 `assets/stitch/manifest.json`，不含 API Key。

- 三版式文章：`ruler.html` / `overprint.html` / `pure.html`。
- 通用语法组件：`components.html`，仅用于原文需要的代码、列表、表格等。
- 15 色系：`color-gallery.html`；其翡翠主色是 `#059669`，三版式示例文章的原始主色却是 `#006948`。换色效果不能当作版式偏差。

封面、导读引用、目录、章节、名片均分别抽取自三版式文章，而不是复用组件演示版。文末互动区使用圆角卡片、顶部图标、标题、提示文案及点赞／收藏／分享静态动作行。原始颜色、字体尺寸、行高、字重、边距、阴影取自 Chromium 对原稿的实际计算样式；`resolved-manifest.json` 记录视口和校验值。主题读取与正文装配离线进行，不需要 Tailwind、网络或凭据。

选择主题 ID 与章节版式为两个独立参数。用户原文始终是正文来源；不得替换成设计稿演示文章。目录、署名与互动各只出现一次。主题候选以索引中已注册且组件库可用的条目为准。

## 设计对照检查要点

1. 封面、引用、目录、章节、名片与互动使用同版式组件，不能混用通用演示版。
2. 名片按各版式保留头像尺寸、间距与阴影；二维码栏仅使用用户提供的真实二维码。
3. 图标采用随附 SVG，检查路径、色彩与装饰几何，不以近似符号替代。
4. 浮光大编号位于左侧；来源计算样式为 58px、9% 透明度及 `top:-12px`，正文使用负边距适配。
5. 来源样式对照以浏览器计算结果为依据，不按 class 字符串顺序推测覆盖关系。
6. 视觉验收使用同文、同色、同宽的对照；HTML 合规和无横向溢出不能替代视觉检查。

计算样式以原始 tag/class/style/**文本**共同标识。不能只按 class 查找：无 class 的名片文本和分享标签继承的颜色不同，否则可能误判文字和图标的继承色。

## 公众号兼容边界

| 内容 | 当前处理 |
|---|---|
| 原稿字体与细节 | 精确尺寸、字重、行高、字距；文章不依赖外部字体，使用系统回退 |
| 名片 | 每版式保留自身结构、阴影与头像尺寸；完整二维码变体含 88px 右栏、72px 图片和关注提示 |
| 真实二维码 | `--qr-url` 明确提供；未提供时使用单独的无二维码变体，不冒用示例身份 |
| 演示二维码 | 仅画廊和同文对照显式使用；原链接重定向到 Google 登录，未登录环境无法显示图片，不伪造二维码 |
| 文末互动提示 | 圆角卡片、顶部图标、标题与提示文案，底部为点赞／收藏／分享静态动作行；不要求三连，不含设计署名 |
| 渐变 | 内联 SVG 分段色带，不用被项目校验警告的 CSS 背景渐变 |
| 引用边饰 | 保留 6px 左饰边及原内边距；用边框代替绝对定位 |
| 浮光编号 | 左侧负边距零占位方案，不使用绝对定位 |
| 徽标底线 | 用边框替代悬浮装饰，仍有细微几何差异 |
| 代码 | 保留原文内容与缩进，逐行文本；不能保证同于示例语法高亮 |
| 桌面响应式 | 生成文章按手机视口适配；公众号不能保留原稿 `sm:` 媒体查询 |
| 网页工具栏、折叠、复制/分享动作 | 工具栏不进正文；折叠静态展开；互动为静态富文本，不能触发微信原生操作或网页点击动作 |

当前模板只保留实际使用的 Material Symbols SVG 图标；字体回退和负边距仍需真实公众号编辑器及不同微信客户端粘贴验证。项目静态校验通过不等于像素级一致。

## 维护、验证与对照

主题修改直接编辑 Markdown。工程验证和画廊刷新可使用：

```bash
python3 scripts/build_stitch_gallery.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/component_lint.py .
```

- `docs/gallery/index.html`：15 色系 × 3 版式，同篇用户示例文章。
- `docs/gallery/comparison.html`：Stitch 原始文章与内联还原，使用同一文章、同一原配色和同一视口，移除外部应用工具栏。用于定位真正的结构差异。
- 对照页可以加载原稿字体；实际生成文章与主画廊不依赖外部字体。

## 文末互动与作者名片

互动卡片包含圆角容器、顶部点赞图标、“既然看到这里了”标题、提示文案及点赞／收藏／分享图标动作行。默认文案为“有用就点个赞，收藏方便回看，也欢迎分享给需要的朋友。”自定义互动文案只渲染一次；正文中的“转发”不自动改写。动作行是静态富文本，不添加点击脚本，不承诺触发微信原生操作，不要求三连。

点赞与收藏动作图标为 `#4B5563`，分享图标为白色、底色为主题主色；顶部点赞徽章使用组件自身配色。图标尺寸与布局以所选主题 Markdown 为准。

默认不生成作者名片。普通 AI 装配仅在用户明确启用并提供真实作者信息时生成，工程渲染器对应显式 `--author`；原文署名默认作为正文保留。简介仅使用用户提供的内容，缺失时不生成空简介节点；真实关注二维码由用户提供，缺失时使用无二维码变体，不填示例身份或占位符。名片与互动分别最多一处，均位于文章末尾。

这些规则是项目的设计与兼容约定，不代表已通过微信官方审核或所有客户端验证。
