# 设计适配历史记录

本文保存来源定制、样式优化与当时的验证记录，不作为当前排版或主题维护规范。文中的轮次、体积和 Chromium 对比结果仅对应当时的产物，不代表本次重新执行或当前版本的验收结果。当前规则见 `references/stitch-design-system.md`，主题以 Markdown 组件库和索引为准。

## 语义色层次

主题编译不再将所有浅底色合并：`surface-container-low` 使用主题 surface；`secondary-container` 使用 55% accent 与 45% surface 混色；`secondary-fixed` / `primary-fixed` 使用 35% accent 与 65% surface 混色。深底简介 `#a7f3d0` 映射到 35% accent 与 65% 白色混色。这样在保留各主题色系的同时区分卡片、强调圆底、高亮及深底辅助文字。它是主题化的层次修复，不是将全部主题强制改为原稿绿色。原稿对照模式不做此换色；原始透明度保留。

## 内联声明的等价精简

`build_stitch_themes.py` 在结构装配与继承变体生成之后执行 `minimize_template_declarations()`，只优化静态模板，不扫描或重写已填入的用户正文：

- 按原声明顺序计算完整的物理 `margin` / `padding`，将简写与冗余单边覆盖合并为更短的等价简写；未指定的边不补值。
- 仅针对可完整解析的 `flex` 简写，删除被其覆盖的前置长属性，或与其值一致的后置长属性。
- 遇到逻辑边距、CSS-wide 值、函数、`!important`、自定义属性等不确定情况保留原写法；SVG 保持原样。
- 不改为 class、外部 CSS 或 `<style>`，不改变模板的父容器契约。仅在序列化后确实更短时采用结果。

本轮 15 色系模板的 HTML 字节由 1,793,755 降至 1,774,840（减少 18,915，约 1.05%），内联声明减少 1,365 条。现有模板已做过多轮继承与结构优化，因此此次以保守等价精简为主，不追求通过改变布局或放宽公众号约束换取更大的降幅。

本地 Chromium 对翡翠、素墨、晚霞三色系 × 三版式 × 示例/综合语法两类文章，在 390 / 677px 下完成 36 组前后对比，检查元素计算样式、几何位置及整页截图，像素差异为零。测试屏蔽了外部图片请求，以免远程加载差异干扰；不代表已验证真实图片加载后的所有布局，也不替代公众号编辑器实测。全部 45 组合仍由自动回归覆盖。

### 第二轮：高频组件共享声明

- 删除完整十六进制纯色 `background` 前方、与其颜色完全一致的 `background-color`；不处理图片、渐变或未知背景值。
- 全局文章容器明确 `font-weight:400`，文章内变体继承普通字重；独立段落模板保留原有字重，标题和局部强调不变。
- 新增 `table_with_cells` / `table_with_cells_in_article` 与 `table_cell_in_table` 配套变体：字号、行高、折行在原生 `<table>` 上定义一次，单元格保留内边距、边框，表头保留独立加粗及背景。独立 `table` / `table_cell` 不变。
- 保留代码容器 gap 和目录卡片宽度约束；本轮不依靠删除潜在布局防护来缩减体积。

相对上一轮，默认翡翠墨规示例（带测试作者和二维码）正文从 25,963 降至 25,541 字节，减少 422（1.63%）。综合语法加 20 行三列表格的同参数正文从 48,910 降至 44,886 字节，减少 4,024（8.23%）。模板因保留独立接口并增加配套变体，总库存字节有所增加；优化指标是实际生成的正文，而不是将库存新增接口误算为压缩收益。

本轮 Chromium 验证覆盖全部 15 色系 × 3 版式 × 示例/长表格综合语法 × 390/677px，共 180 组前后对比，整页截图像素及元素几何一致。表格祖先节点的字号/行高因共享声明而有意改变，单元格及可见文本的计算样式保持一致。仍屏蔽远程图片请求，尚未进行真实公众号粘贴及微信客户端验证。

### 第三轮：代码标题字体、左对齐与零宽边框

- 文件名和语言标签的相同等宽字体栈上移至代码标题栏，共享一次；标签本身的字号、行高及颜色不变，代码正文保留独立字体契约。标题栏内无文字的装饰点也会继承该字体，但其固定几何与绘制不变。
- 配套表格内的左对齐正文单元格继承表格的 `text-align:left`，居中、右对齐仍显式声明；所有表头仍显式声明对齐，避免原生 `<th>` 的居中默认值。
- 仅针对没有侧边框及 border-image 覆盖的配套表格，将零宽 `border:0 solid rgba(...)` 简化为 `border:0`。独立表格接口不变，不将此规则推广到任意节点。

相对第二轮，每个代码块减少 61 字节，每张配套表格固定减少 27 字节，每个左对齐正文单元格再减少 16 字节。全部模板 HTML 合计减少 4,470 字节、60 条声明。上述带长表格综合文章从 44,886 降至 44,419 字节，减少 467（1.04%）；不含代码/表格的示例文章维持 25,541 字节不变。

第三轮同样完成全色系、三版式、两类文章和两种宽度的 180 组 Chromium 对比：元素几何、可见文字样式及整页截图像素一致。共享字体导致无文字的代码标题容器/装饰节点计算字体改变，此项不要求计算值相同；文字节点字体逐项比较。远程图片仍被屏蔽，公众号粘贴验证仍需另行进行。
