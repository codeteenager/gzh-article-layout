# Magazine Markdown Converter · 设计来源与公众号适配

## 原稿与主题不能混为一谈

来源项目：`projects/9891162362575619920`。五份原始导出及 SHA-256 清单保存在 `assets/stitch/manifest.json`，不含 API Key。

- 三版式文章：`ruler.html` / `overprint.html` / `pure.html`。
- 通用语法组件：`components.html`，仅用于原文需要的代码、列表、表格等。
- 15 色系：`color-gallery.html`；其翡翠主色是 `#059669`，三版式示例文章的原始主色却是 `#006948`。换色效果不能当作版式偏差。

封面、导读引用、目录、章节、名片均分别抽取自三版式文章，而不是复用组件演示版。文末互动区已按公众号适配规则重设计，不再还原原稿的三按钮卡片。原始颜色、字体尺寸、行高、字重、边距、阴影取自 Chromium 对原稿的实际计算样式；`resolved-manifest.json` 记录视口和校验值。构建过程离线，不需要 Tailwind、网络或凭据。

选择主题 ID 与章节版式为两个独立参数。用户原文始终是正文来源；不得替换成设计稿演示文章。目录、署名与互动各只出现一次。旧主题已删除，不再自动参与生成。

## 本次差异排查

之前的主要失真来自：

1. 复用了通用组件演示版的封面、名片、分享区，而不是三张文章稿的真实组件。
2. 删除整个二维码栏及关注说明；统一签名模板抹平了 32/36px 头像、间距和阴影差异。
3. 用心形、圆圈、箭头替代点赞、在看、分享图标，渐变变成单色，装饰被直接丢弃。
4. 浮光大编号被放在右侧；原稿为左侧 `top:-12px`、58px、9% 透明度。
5. 自编译器错误推测灰阶和字体；按照 class 字符串顺序覆盖，未遵循浏览器真实结果。
6. 仅验证了 HTML 合规和无横向溢出，没有以同文同宽原稿作视觉验收。

计算样式以原始 tag/class/style/**文本**共同标识。不能只按 class 查找：无 class 的名片文本和分享标签继承的颜色不同，否则会让“点赞 / 在看”错误变白。

## 已恢复与保留的兼容边界

| 内容 | 当前处理 |
|---|---|
| 原稿字体与细节 | 精确尺寸、字重、行高、字距；文章不依赖外部字体，使用系统回退 |
| 名片 | 每版式保留自身结构、阴影与头像尺寸；完整二维码变体含 88px 右栏、72px 图片和关注提示 |
| 真实二维码 | `--qr-url` 明确提供；未提供时使用单独的无二维码变体，不冒用示例身份 |
| 演示二维码 | 仅画廊和同文对照显式使用；原链接重定向到 Google 登录，未登录环境无法显示图片，不伪造二维码 |
| 文末互动提示 | 细分隔线与普通文字，默认邀请点赞、分享、在看；无圆形装饰、假按钮、三连要求或设计署名；来源对照仍保留原稿 |
| 渐变 | 内联 SVG 分段色带，不用被项目校验警告的 CSS 背景渐变 |
| 引用边饰 | 保留 6px 左饰边及原内边距；用边框代替绝对定位 |
| 浮光编号 | 左侧负边距零占位方案代替绝对定位；不是把数字改放右侧 |
| 徽标底线 | 用边框替代悬浮装饰，仍有细微几何差异 |
| 代码 | 保留原文内容与缩进，逐行文本；不能保证同于示例语法高亮 |
| 桌面响应式 | 生成文章按手机视口适配；公众号不能保留原稿 `sm:` 媒体查询 |
| 网页工具栏、折叠、复制/分享动作 | 工具栏不进正文；折叠静态展开；互动仅文字邀请，不能冒充可执行的网页按钮 |

当前模板只保留实际使用的 Material Symbols SVG 图标；字体回退和负边距仍需真实公众号编辑器及不同微信客户端粘贴验证。项目静态校验通过不等于像素级一致。

## 构建、对照与生成

```bash
python3 scripts/build_stitch_themes.py
python3 scripts/build_stitch_gallery.py
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/component_lint.py .
python3 scripts/render_stitch_article.py assets/sample-article.md \
  --theme emerald --layout ruler --author 作者 --bio 简介 \
  --qr-url https://example.com/your-qr.png --output /tmp/公众号正文.html
```

- `docs/gallery/index.html`：15 色系 × 3 版式，同篇用户示例文章。
- `docs/gallery/comparison.html`：Stitch 原始文章与内联还原，使用同一文章、同一原配色和同一视口，移除外部应用工具栏。用于定位真正的结构差异。
- 对照页可以加载原稿字体；实际生成文章与主画廊不依赖外部字体。

## 语义色层次

主题编译不再将所有浅底色合并：`surface-container-low` 使用主题 surface；`secondary-container` 使用 55% accent 与 45% surface 混色；`secondary-fixed` / `primary-fixed` 使用 35% accent 与 65% surface 混色。深底简介 `#a7f3d0` 映射到 35% accent 与 65% 白色混色。这样在保留各主题色系的同时区分卡片、强调圆底、高亮及深底辅助文字。它是主题化的层次修复，不是将全部主题强制改为原稿绿色。原稿对照模式不做此换色；原始透明度保留。

## 文末互动与关注转化

点赞、分享、在看作为可选互动邀请，不等同于关注入口。默认文案为“如果这篇对你有帮助，欢迎点赞、分享给需要的朋友，或点个在看。”仅使用细分隔线与文字，不画无法触发微信原生操作的按钮，不要求三连。真实作者名片及用户提供的关注二维码负责身份展示与关注引导；缺失信息不补造。自定义互动文案只渲染一次，不附加固定标签，正文中的“转发”不自动改写。这是产品设计约定，不代表已通过微信官方审核或所有客户端验证。
